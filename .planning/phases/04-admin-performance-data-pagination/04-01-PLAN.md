<objective>
Implement the server-side pagination foundation and performance optimizations for the Eduverse admin panel: extend the Firestore test harness with cursor pagination and count aggregation; introduce `PaginatedResult<T>`; implement cursor-paginated `getUsersPaginated` and `getPurchasesPaginated` in `FirebaseAdminService` with T-04-01 administrator authorization; and refactor `AdminStatsService` to stream the cached `admin_stats/dashboard` document with constructor dependency injection instead of running 30s polling loops across raw collections.

Purpose: Eliminate massive read volume and client memory overhead, dropping initial dashboard reads by >60% and providing clean cursor pagination contracts for the admin UI.
Output: Extended test fakes, pagination service methods, cached stats service, and two automated unit test suites.
</objective>
